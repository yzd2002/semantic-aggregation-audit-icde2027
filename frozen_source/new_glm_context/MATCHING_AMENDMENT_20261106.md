# Forward amendment after CPU tokenizer preflight, before GLM inference

Built with glm-4. See LICENSE.

The earlier Qwen/Smol context results and Qwen/Smol/GLM decision results were already known when this new GLM context replication was designed. This is not a preregistration of the original research. No GLM context judgment has yet occurred. The first CPU preflight found 34 of the original 256 targets (4 DBLP–ACM and 30 BoolQ) with near/random prompt-length differences exceeding 24 tokens under the exact local GLM tokenizer, while all complete features remained below 512 tokens and every prompt plus the 128-token output cap remained below 4096. The initial compiled requests and initial CPU report are preserved, not overwritten as historical certificates.

The supervising root task authorized this amendment before any GLM context inference. Keep every original target, target order, full feature string, near triplet, original source bank, target ID, local ID, input placement, predicate instruction, scope, repeat and original mixed/serial schedule. Keep the original random triplets for the 222 targets that pass the GLM 24-token bound. Only the other 34 random triplets are redrawn by the following fixed, label-blind rule.

Process task order DBLP–ACM then BoolQ and selected_ordinal order. Use a fresh Python Random(2026110603) stream, not a stream selected for a favorable result. Source candidates are the preserved original label-free training background banks. Existing reserve-identity exclusions, complete-feature deduplication and original near triplets stay unchanged. A newly proposed record must satisfy the 512-token unwrapped complete-feature eligibility bound under all three exact local tokenizers; exclusions and counts are retained. At each width 16, then 32, then 64, construct the original per-position candidate pools using a feature-length difference at most that width in all three tokenizers, exclude observed identities of all three near records, and draw each next record uniformly from remaining candidates excluding identities already drawn within the random triplet. Stop a width if its candidate pool becomes empty. Consider at most 2000 complete-triplet proposals per width, as in the original rule. Preserve each proposal, its IDs, width, attempt count, full prompt lengths under all three native wrappers, and rejection reason. Accept the first proposal whose full prompts differ from the fixed near context by at most 24 tokens for every scope in all three tokenizers and whose prompt-plus-128 lengths fit 4096. Gold labels and model judgments never enter this routine. No unbounded search or target replacement is permitted; a failure is an explicitly unevaluable target/design, to be reported before requesting GPU authorization.

The primary GLM arm uses all 256 fixed targets with these jointly length-matched contexts. The exact historical context arm is secondary: retain and execute the 34 targets' original random contexts for every scope and repeat (204 extra mixed calls), sharing their already observed near/singleton calls. The exact historical serial arm similarly adds the original random-context requests for 11 affected targets inside the predeclared first-32-per-task subset (66 extra blocking single-request calls). The other historical requests share identical primary observations. Shared observations are explicitly linked to their unique raw call and do not create independent samples or additional inference calls.

Execution order is the complete primary mixed run (3584 requests), historical extra mixed requests (204), primary serial run (896), historical extra serial requests (66), all on the same loaded native GLM engine. Additional mixed requests use a separate schedule shuffled by Python Random(2026110604), in task/selected-ordinal/scope/context/repeat construction order; their blocks contain at most 64 requests. Additional serial requests use Python Random(2026110605) and one blocking request per invocation. The original main and serial schedules are unchanged. Twenty original diagnostic calls precede all scientific inference. The fixed budget is 4750 scientific requests, 20 diagnostic requests, 4770 total; item-label and native-token budgets are generated before inference and included in the final freeze.

The original all-target statistical functions, bootstrap seed/draws, strict parser and completion rules remain unchanged. The two new GLM primary full-first contrasts retain the original 98.75% bootstrap interval as a conservative criterion: lower endpoint greater than zero. This is not a claim of a single prospectively controlled FWER family spanning the four already completed Qwen/Smol comparisons plus these two GLM comparisons. All exact-historical, paired arm, serial, reference-transport and original 222-length-pass-subset results are secondary descriptions, with the old secondary 95% intervals and denominators reported. No observed outcome can change a target, prompt, arm, completion criterion or reported result.
