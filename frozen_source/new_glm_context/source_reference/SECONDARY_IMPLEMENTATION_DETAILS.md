# Pre-inference secondary implementation details

Supplement A uses every selected target, independent of common12/common14. Reference calls are singleton repeat 1/2 and random full-first repeat 1/2. All four must validate and agree. Each passing target retains the number (0, 1, or 2) of valid near full-first calls. Any/stable flip fractions use passing targets with two valid near calls, while passing targets with invalid/unreturned near calls remain explicitly counted. Gold is used only to evaluate reference errors and random-to-near improvement/worsening. No near call participates in qualification.

Supplement B is implemented by prepare_serial.py and appends new files without changing the original schedule or request files. It sorts the chosen subset by task, selected ordinal, main scope construction order, context, repeat; Python Random(2026110205) shuffles that sequence. Each serial request has the main request ID prefixed by `serial/` and stores source_main_request_id. Its ordinal equals its one-request block index. Prompt bytes, explicit token IDs, requested IDs, output order, grammar and ID mapping are copied exactly from the main prepared record and rechecked before execution. The original main run finishes first on the same loaded engine; the serial loop makes one blocking generate call per record. Model configuration and caps remain unchanged.

The original primary analyzer remains analyze.py; supplement results are produced separately by secondary.py. Each mode's descriptive subset estimates use its common12 set within selected ordinals 0..31, and each retains its own explicit completion denominators. Serial-minus-mixed differences use the intersection complete across both modes' contextual 12 calls, selected-ordinal order, and 4000 shared target-index draws from NumPy default_rng(2026110204), reset per task/model comparison. Only unadjusted 95% linear-percentile intervals are produced for this supplement. The two paired scope contrast differences are `(serial E_only − serial E_first) − (mixed E_only − mixed E_first)` and the analogous full-last expression. These are not additional primary tests.

Stable within-target changes require both near repeats to agree, both random repeats to agree, and the two stable labels to differ. They are reported both on each mode's common12 set and on the explicitly counted set valid for that scope's four calls. COUNT diagnostics retain the fixed selected 32-target relation (or the predeclared shortfall if fewer exist), never a common/available-case denominator. Reference-probe interpretation and serial-after-mixed limitations are as stated in the supplement.

All submission ledgers reject unknown IDs, repeated IDs, and any mismatch to frozen block membership. The serial ledger must have exactly one request per submitted block. Actual model-run costs distinguish main, serial and diagnostics; secondary A reuses six existing calls per target and adds no inference. Synthetic CPU tests are saved separately under cpu_checks and contain no model responses.
