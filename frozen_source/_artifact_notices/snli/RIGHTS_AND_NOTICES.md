## Datasets

**DBLP–ACM.** The original bibliographic entity-resolution benchmark is credited to the Database Group of Prof. Erhard Rahm, Leipzig University. The [official benchmark page](https://dbs.uni-leipzig.de/research/projects/benchmark-datasets-for-entity-resolution) states, after its binary entity-resolution dataset table, a January 2019 CC BY 4.0 release and asks users to credit that page and Köpcke, Thor, and Rahm, *Evaluation of Entity Resolution Approaches on Real-world Match Problems*, PVLDB 3(1–2), 2010. See the [CC BY 4.0 terms](https://creativecommons.org/licenses/by/4.0/).

The five CSV files used here are the structured DBLP–ACM processing/splits distributed with DeepMatcher, documented at [fixed revision 82445a5](https://github.com/anhaidgroup/deepmatcher/blob/82445a5425353a9b5dee51c61ec517577bbebb8d/Datasets.md#dblp-acm). Credit Mudgal et al., *Deep Learning for Entity Matching: A Design Space Exploration*, SIGMOD 2018, in addition to the original benchmark. DeepMatcher's software license is not used as a license for the data. The preserved official-page copy, exact source URL/hash receipts and byte-equivalent pinned mirror record are under this package's `rights_evidence/`. The recovery-time source page is evidence acquired in November 2026, not a restoration of missing older acquisition receipts. The benchmark page licenses the underlying data; no separate license for DeepMatcher's split annotations is invented here.

Research adaptations: source IDs and full citation fields are preserved; selected and reserved subsets, feature wrappers, random/diversity partitions, fixed request schedules and audit traces are produced. The full CSV bytes remain hash matched to the upstream distributed files. Original and adapted benchmark data are attributed to the original sources, not to this project.

**BoolQ.** Credit Christopher Clark, Kenton Lee, Ming-Wei Chang, Tom Kwiatkowski, Michael Collins and Kristina Toutanova, *BoolQ: Exploring the Surprising Difficulty of Natural Yes/No Questions*, NAACL 2019. The [publisher's pinned README](https://github.com/google-research-datasets/boolean-questions/blob/90af34107399cc7a446b373dc4ee35b8001da7c2/README.md#license) declares [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The package retains complete question/passage fields and their source identifiers; conversions, selected subsets, wrappers and partitions are adaptations. Redistributed BoolQ data and its adaptations retain CC BY-SA 3.0. The local files are deterministic JSONL conversions with row indices; byte equivalence to the original Google Cloud JSONL transport is not claimed. Their preserved source checks and hashes specify the actual input identity.

**SNLI.** Credit Samuel R. Bowman, Gabor Angeli, Christopher Potts and Christopher D. Manning, *A large annotated corpus for learning natural language inference*, EMNLP 2015; credit the Stanford NLP Group and the Flickr30k contribution by Peter Young, Alice Lai, Micah Hodosh and Julia Hockenmaier (TACL 2014). The [fixed Stanford publisher card](https://huggingface.co/datasets/stanfordnlp/snli/blob/cdb5c3d5eed6ead6e5a341c8e56e669bb666725b/README.md) declares [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Adaptations include subset selection, stable split/index IDs, feature wrappers and the binary mapping entailment→Y, neutral/contradiction→N. Premises/hypotheses remain complete. Redistributed SNLI data and adaptations retain CC BY-SA 4.0. Fixed Parquet objects were transported through hf-mirror.com/public Hugging Face CDN; the original Stanford ZIP was unavailable and was not compared. Detailed notices and retrieval failures remain in `new_snli_context/SNLI_DATA_LICENSE_AND_ATTRIBUTION.txt` and `sources/`.

No ACORD, TREC-COVID/CORD-19, old product pilot, model weights, model cache or unrelated project data is selected for these final-paper modules.

## CPU audit scope and historical boundaries

“Independent” in the reports describes separately written mathematical/agent code verification of preserved outcomes. It does not mean an external human review or independently rerun model inference. Current CPU relocation tests use the installed Python 3.12.11 environment, NumPy 2.2.6 and, for SNLI source checks, PyArrow 22.0.0.

The decision dependency is restricted to the original development data, all 36 immutable policies, selector eligibility/calibration ledgers, actual tokens and deterministic input preparation needed by the final transfer study. Old TEST results are not a final-paper evidence module. Original recovery notes explicitly distinguish the recovered numerical closure from incomplete historical 73/242-file provenance and missing older certificates. This package does not turn those missing records into a historical full-freeze PASS.
