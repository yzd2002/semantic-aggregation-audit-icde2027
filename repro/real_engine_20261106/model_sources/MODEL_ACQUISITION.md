# Exact model acquisition and GPU scope

The complete compact CPU replay needs no model weights or GPU. It recomputes the mathematics from retained actual outputs, partitions, reference vectors, source labels and token/cache receipts. It does not retokenize omitted inputs or reproduce GPU latency.

For a new GPU execution, `MODEL_DOWNLOAD_PLAN.json` supplies each publisher URL, fixed revision and expected SHA-256. Qwen3-4B-Instruct-2507 is pinned to `cdbee75f17c01a7cc42f958dc650907174af0554`; GLM-4-9B-Chat to `bd8234fe5e0c09c48637a92abb0c797cb5fa0e73`. The canonical GLM organization is now `zai-org`; its former `THUDM` address redirects to the same public repository. Obtain and use each model under its own included license. **Built with glm-4.**

After inference, the documented public mirror's Git/LFS metadata was compared with the frozen local model files: all 12 Qwen publisher files and all 22 GLM non-hidden publisher files matched. This lookup identified download sources; it did not replace any weights, change the experiment, or freshly download the large weight files. See the preserved metadata and comparison receipts. Producer-only ModelScope bookkeeping files are outside that publisher file set and are not distributed as model assets or login material.

Preserve the local directory name `glm-4-9b-chat`: the GLM tokenizer guard binds its exact dynamic module name and source SHA. The unmodified experiment sources retain the producer paths shown in the plan; reconstruct inputs at the documented layout, or bind-mount them at those paths. Model/protocol hashes and the explicit reviewed runtime amendments remain authoritative. Do not silently edit the frozen code, change precision, substitute a model or remove a failed stage while describing a new run as the recorded experiment.

Recorded inference used native vLLM 0.10.2, PyTorch 2.8.0+cu128, Transformers 4.57.1 and BF16 on NVIDIA GeForce RTX 5090 cards with 32 GB memory, one model per assigned card. Live LOTUS/SemBench source commits, the isolated native-filter environment, controls, cache-reset observations and actual effective settings are included in the scientific foundation module. Native singleton output and the custom batched output contract differ, as explained in the paper. The source-input fetchers reconstruct the exact prepared records and native requests without including news text in this repository.

The provided model/code/configuration/data identities make a new run inspectable. A clean-machine GPU reexecution has **not** been performed here; its numeric results and timings cannot be promised identical to a recorded temperature-zero run. CPU replay, source reconstruction, source-ZIP rebuild, producer-side runtime checks and independent simulated paper reviews are separate forms of evidence.
