# Public filename aliases

GitHub normalizes non-ASCII release asset names. The following explicit ASCII filenames avoid ambiguous downloads. Only outer filenames differ; SHA-256 and all ZIP member bytes and names remain unchanged. The index preserves original_name, so the scientific source provenance keeps its original archive references.

- `ACORD_无原文可重建复现候选.zip` → `acord_qwen_textfree.zip`
- `ACORD_SmolLM2_无原文复现候选.zip` → `acord_smollm2_textfree.zip`
- `ACORD_批次敏感性_无原文复现候选.zip` → `acord_batch_textfree.zip`
