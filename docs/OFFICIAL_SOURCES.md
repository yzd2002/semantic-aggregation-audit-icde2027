# Official publication and source evidence

Checked 2026-11-06. These observations are separate from the scientific claims.

- [ICDE 2027 research/EAB CFP](https://icde2027.github.io/cf-research-papers):
  EAB requires all necessary reproduction artifacts on a standard openly
  accessible service; no missing-material exemption. The title prefix and
  single-blind manuscript/author requirements also apply.
- [GitHub large-file guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github):
  ordinary Git warns above 50 MiB and blocks files above 100 MiB; Releases are
  an alternative for distribution.
- [GitHub Releases guidance](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases):
  releases can attach binary assets to a tagged source revision; each file must
  be below 2 GiB, up to 1,000 assets. Verify the attachments, not only the auto
  generated source archive.
- [Pinned WANDS license](https://github.com/wayfair/WANDS/blob/3b74dcf4ba29ab8ff3e6a50b5b09fc627cb882b5/LICENSE)
  and [pinned ESCI license](https://github.com/amazon-science/esci-data/blob/7916cdf6ab75a462e77f20ab40428a10923998d5/LICENSE):
  retained publisher license texts are MIT and Apache 2.0 respectively.
- [Pinned ACORD README](https://github.com/The-Atticus-Project/acord/blob/942b33a7c6fed7ead362c7c296401086f8bc0321/README.md)
  and [repository LICENSE](https://github.com/The-Atticus-Project/acord/blob/942b33a7c6fed7ead362c7c296401086f8bc0321/LICENSE):
  the dataset declaration is CC BY 4.0, and the repository license file is MIT.
  These publisher statements do not change the scope of the reconstruction
  supplements or erase underlying-source and linkability considerations.
