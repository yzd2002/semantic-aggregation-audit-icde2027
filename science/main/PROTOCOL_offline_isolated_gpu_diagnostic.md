# Offline isolated GPU environment diagnostic

This secondary, post-hoc diagnostic was designed after the clean public-index resolution in `PROTOCOL_clean_gpu_environment.md` failed to connect. It uses copies of installed local packages, not a clean download, a fresh machine or a reconstruction of the exact original runtime. Earlier benchmark results remain unchanged.

Before creating the environment, select the transitive runtime requirements of vLLM 0.10.2 and the recorded analysis packages, including required extras, from the local host and the three-package dependency overlay. Require every installed package version to satisfy its selected dependency constraints; freeze the selected package names, versions, extras and source choice in `CLEAN_GPU_OFFLINE_DEPENDENCY_GRAPH.json`. Copy only the package files listed in their installed distribution metadata into a new Python 3.12 virtual environment with system site packages disabled. Refuse changed versions, missing package files, unresolved requirements, path traversal, or conflicting files. Do not copy external entrypoint scripts. Retain a manifest of the copied paths, their source and SHA-256; independently hash-check both source and destination. The manifest verifies copying from this host, not provenance from a trusted public wheel or security of installed packages.

Check the resulting environment's complete package metadata with an independent dependency checker and verify that its Python import path excludes host site packages. Record environment versions and full dependency-check output. Do not change the host, existing overlay or previous experiments. Keep temporary environment and caches on the temporary filesystem, avoiding the nearly full system disk.

Only if the isolated-environment and dependency checks pass, execute the unmodified `run_vllm_declared_deps_smoke.py` with the existing local Qwen model and V1, in a new output directory. That runner requires an idle GPU, checks ownership during inference, and stops its own process if a foreign GPU process appears. Preserve any failure, raw responses, controls and logs. Verify the outputs independently with `verify_vllm_declared_deps_smoke.py`, including the local tokenizer. Compare with the earlier overlay synthetic output only as a descriptive same-hardware check. It does not validate benchmark quality, installation on another machine, or all experimental paths.

Freeze this protocol, the selection graph, builder, file verifier, original smoke scripts and their prior input hashes before copying or inference. Do not replace a failed or earlier output. The Python binary, GPU driver, operating system and model files remain host dependencies, and executable entrypoints are not recreated.
