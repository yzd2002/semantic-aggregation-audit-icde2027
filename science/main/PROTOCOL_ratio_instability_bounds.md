# Ratio-error floors from observed output differences

This is a post-hoc deterministic analysis after the WANDS holdout and its summary were observed. It introduces no new model calls, labeled sample, probabilistic guarantee or independence claim. The underlying inequalities use the triangle inequality and integer counts; they are not claimed as a new general theorem about model disagreement.

For two complete binary output vectors on the same fixed pool of size `n>0`, let `p_a` and `p_b` be their positive counts and let `p_s` be the positive count of an arbitrary common binary reference. Then the larger of the two absolute ratio errors is at least `ceil(abs(p_a-p_b)/2)/n`. The bound is sharp because any integer between the two counts is a realizable reference count; an integer midpoint attains the minimum maximum error. This bound can be zero despite many candidate-label disagreements. It requires the same pool and common reference, not correct predictions or any error model.

For `Q>0` pools **all of the same size `n`**, define query-macro MAE separately for the two outputs against arbitrary fixed reference counts. The worse of the two MAEs is at least `ceil(sum_q(abs(p_aq-p_bq))/2)/(Q*n)`. This is sharp over unrestricted reference counts: within each interval between the two positive counts, assign a feasible integer error to the first output. Those integer errors can sum to any value from zero through the total gap; allocating half, rounded up, attains the bound. Different pools may have different worse outputs. The equal-size requirement is essential for this exact aggregate expression; no such exact result is claimed for differing pool sizes, constrained references, or production distributions.
