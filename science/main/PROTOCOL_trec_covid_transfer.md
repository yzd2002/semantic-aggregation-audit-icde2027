# Cross-domain TREC-COVID transfer check

This exploratory external-domain study was designed after the product-search results were seen, but before selecting the TREC-COVID candidates or generating their model outputs. It tests an adaptation of the fixed-pool contract and selective fallback to biomedical literature relevance. It is not a new user-satisfaction benchmark, a clinical recommendation system, a comparison with the official TREC leaderboard, or evidence that previous product-search improvements generalize. Model pretraining exposure to public TREC-COVID is unknown. All results, including failed, null and adverse results, will be retained.

## Source and sample

Use the 50 final topics and cumulative Round 5 judgments of TREC-COVID Complete from NIST (https://ir.nist.gov/covidSubmit/data.html), paired by CORD ID with the corpus in the BEIR TREC-COVID archive at https://public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/trec-covid.zip. The BEIR project lists MD5 `ce62140cb23feb9becf6270d0d1fe6d1` for this archive. Record SHA-256 of each retrieved source. Check the archive hash and reject duplicate conflicting topic–document judgments or duplicate corpus IDs.

For each of the 50 numbered topics, keep **only explicitly judged** CORD IDs with a matching BEIR title and nonempty abstract. Do not infer that any unjudged document is negative. If a topic has fewer than 32 eligible documents, record its eligibility count and omit that topic; do not replace it by another source. Otherwise sort eligible CORD IDs lexicographically, draw 32 without replacement using `random.Random(20271031 + int(topic_id)).sample`, and keep the returned sample order. This selection does not use judgment grade. Store original query, question and narrative, corpus ID, judgment, title and abstract, with model input truncated to 200 title characters and 800 abstract characters after whitespace normalization. Set reference Y only for official judgment 2 (fully relevant); judgments 1 and 0 are N. This is a deliberately strict binary reference, not the standard graded-retrieval metric. Report eligible counts, grade counts, repeated document IDs, source exclusions and any missing source fields.

## Execution

Use Qwen3-4B-Instruct-2507 with recorded model files, vLLM 0.10.2 V1 and the process-local declared-dependency overlay from the synthetic dependency check; this is not the original product-experiment environment, and the inherited environment has other unresolved package conflicts. Use one RTX 5090, bfloat16, temperature zero, 4,096-token context, eager mode, prefix caching and at most 16 concurrent sequences. Check that no other GPU process is present before loading and check ownership after loading and before every generation; stop our own run if another GPU process appears. Do not stop other processes.

Adapt the product task by providing the official topic query, question and narrative directly as the task specification, and a document title and abstract in place of product text. Thus this is an adaptation, not an exact replay of the WANDS-generated-specification pipeline. For each 32-document pool, use four consecutive eight-document chunks with local IDs 1–8, an explicitly keyed Y/N JSON result, a strict parser and the existing fixed-key grammar. Use a 128-token cap and one bounded format retry for keyed outputs, and a four-token cap and one bounded retry for individual outputs. Before any candidate inference, require that an unconstrained incompatible BANANA control fails both keyed and single-label parsers and that both guided controls pass their parsers. Preserve prompts via reconstructible source records and prompt hashes, initial and final responses, finish reasons, retries, token counts and worst context lengths.

Run in fixed order: original presentation, reversal within each chunk with unchanged local IDs, actual pointwise calls only for candidates with differing valid keyed labels, identical-prompt original replay, and full pointwise calls for all candidates. An invalid keyed chunk or required failed pointwise response makes the selective pool non-estimable; never fill missing results with N. Keep agreeing labels and replace disagreements with the actual selective pointwise label. The full pointwise run is a separate comparator and must not supply selective-plan decisions. Record total calls and logical token counts separately; batch timing is not online latency.

## Analysis

The pre-specified primary comparison is query-macro ratio MAE of actual selective fallback minus canonical keyed original, over pools jointly complete under original, reversal, replay, full pointwise and selective fallback. Use 4,000 paired query-cluster bootstrap draws from NumPy `default_rng(20271032)` and report the point difference and the 2.5th and 97.5th percentiles regardless of sign; this interval is conditional on this selected, judged sample and is not a guarantee for a population or for unjudged documents. A non-overlapping interval does not establish clinical utility or exclude multiple-comparison and model-selection effects.

Also report all-pool completion, pooled F1 and balanced accuracy, query-macro ratio MAE for original, selective, full pointwise, all-negative, all-positive and an all-query-words lexical rule; forward-versus-reversed and forward-versus-replay label change rates; and selective-versus-later-full pointwise changes on matched disagreement calls. Report numbers of topics, judgments, duplicate CORD IDs and logical calls/tokens. Source topics and models are public, the prompts and domain differ from WANDS, abstracts are truncated, relevance judgments can use information not visible to the model, candidates are selected from judged document pools, and documents may repeat across topics. No causal claim about candidate order, grammar, source, model, or query specification is justified by these comparisons.

The NIST topics and qrels and the BEIR source identity will be recorded for reconstruction. The local artifact can contain sampled article metadata for private review, but each source document's rights and the terms for redistribution must be checked before publishing any sampled text. Do not assign an unverified blanket license to the CORD-19 article content.
