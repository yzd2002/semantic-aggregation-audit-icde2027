# Query–document crossed sensitivity, fixed after selection and before inference

The selected inputs contain document IDs appearing in multiple topics. After observing this sample structure, but before generating or viewing any candidate model outputs, add a secondary sensitivity analysis to the original unchanged query-bootstrap comparison. This is not the primary analysis and does not claim coverage for the fixed-pool estimand.

Among the common-complete pools, sort the distinct sampled CORD IDs lexicographically and retain topics in saved order. In each of 4,000 draws, use NumPy `default_rng(20271033)` to resample the number of observed topics with replacement first, and independently resample the number of distinct observed document IDs with replacement second. Weight each document occurrence by its sampled document multiplicity, compute its topic's weighted gold, canonical and selective positive fractions, subtract absolute canonical ratio error from absolute selective ratio error, then average over resampled topic multiplicities. A selected topic with zero total document weight invalidates the analysis rather than being silently dropped. Report the 2.5th and 97.5th percentiles. The procedure changes within-topic candidate weights and does not correct judged-pool selection, limited visible document text, pretraining exposure or multiple comparisons.
