# Post-hoc failure-aware fallback on all attempted product pools

This diagnostic is defined after the original outputs, labels, common-complete comparisons and partial-output analyses were already observed. It uses no new model calls and is not a blind or confirmatory test. It asks how two explicitly specified, trace-derived fallback policies would behave when every attempted query must return a complete ratio. The policies are calculated from recorded outputs; they were not separately executed as online services and carry no measured latency or monetary cost.

Apply the same definitions to Qwen and SmolLM2 on the original ESCI 250-query and WANDS 160-query runs. Use each saved query and candidate order and the original task-specific binary gold labels. Confirm input/output query and candidate alignment; all saved complete compact-fallback predictions must equal the strict reconstruction of their final chunk responses. For each final compact chunk, accept the entire chunk only if its final response is a string of exactly the chunk size and contains solely Y/N; otherwise accept none of that chunk. Check chunk indices are valid, disjoint and cover the whole pool. Do not salvage characters from an invalid chunk.

Use the existing deterministic all-query-words rule: case-fold the query and candidate text, take each set of `re.findall(r'\w+', ...)` tokens, and return Y iff the nonempty set of query terms is a subset of the candidate terms. The rule may be a weak semantic comparator; it has no access to the reference labels.

For a pool where the saved compact plan completed, retain its saved prediction under both policies. For an incomplete pool, compute two alternatives:

1. **Whole-pool lexical fallback:** discard the partial model judgments and use the lexical rule for every candidate in that pool.
2. **Partial lexical completion:** retain judgments from valid saved chunks and fill only candidates in invalid chunks with the lexical rule.

Both return a full vector on every attempted pool. They are alternatives to the original contract's explicit failure, not evidence that partial judgments are correct or that the original program actually executed either policy. Assert that the recorded compact output is `None` exactly when the strict recovered vector has a missing value. Compare the two policies with each model's saved pointwise plan, the lexical rule on every pool, and all-Y/all-N constants. Report original compact completion and failed-pool counts; selected model and lexical candidate counts for each policy; pooled candidate F1 and balanced accuracy; query-macro ratio MAE; and the per-query predictions, input/output identity and whether fallback was used. Both datasets' pointwise plans are required to have complete binary predictions for every attempted pool; otherwise fail and retain the diagnostic rather than silently change the comparison.

For each of the four dataset/model combinations, calculate 4,000 paired query-cluster bootstrap draws with NumPy `default_rng`: seeds 20271041, 20271042, 20271043 and 20271044 in the order ESCI/Qwen, WANDS/Qwen, ESCI/SmolLM2 and WANDS/SmolLM2. Report point differences and 2.5th/97.5th percentiles for ratio MAE: whole-pool fallback minus pointwise, partial completion minus pointwise, and partial completion minus whole-pool fallback. These are unadjusted, retrospective descriptive intervals for selected judged queries, not causal estimates, blind tests, user-satisfaction guarantees or evidence of superiority at deployment scale. Do not select or suppress findings based on sign or significance. Product IDs can repeat across queries and are not independently resampled here.

Freeze this protocol, the analysis, an independent verifier, edge-case checks and all four input/output sources and recorded summaries before computing this diagnostic. Reconstruct fallback decisions independently from raw final chunks and lexical terms, and check all saved per-query decisions, counts, pooled statistics and bootstrap intervals. The already observed results and dataset labels were visible before this protocol; freezing does not erase that exposure.
