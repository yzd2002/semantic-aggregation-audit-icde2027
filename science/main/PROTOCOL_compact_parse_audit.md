# Post-hoc delimiter-tolerant parsing audit

After observing both the strict-format failures and the example-removal ablation outputs, inspect the saved final SmolLM2 compact responses without making any additional model calls. Compare the previously used strict parser with a narrowly defined delimiter-tolerant parser. The latter may remove whitespace and commas and one optional trailing period, but accepts the result only when the entire response contains no other characters and exactly the required number of uppercase Y/N labels. It must reject explanations, missing or extra labels, unexpected punctuation and ambiguous words. It does not insert or delete decisions and cannot detect semantic mistakes or positional swaps.

Apply both parsers to both the original compact-fallback outputs and the example-removed outputs on the same ESCI and WANDS candidate chunks, using the final response saved after at most one retry. Keep the earlier strict results unchanged. Reconstruct a pool only if all of its chunks validate, and report chunk and pool completion plus F1, balanced accuracy, and query-macro ratio MAE on each parser/prompt combination's own completed pools. Where two combinations complete common pools, report the intersection size before any paired quality comparison; otherwise state that no paired comparison is possible. Include the deterministic all-N and all-Y baselines on each completed subset. Model prompts and accepted samples differ, so this diagnostic does not isolate a causal model effect or certify semantic quality. Preserve raw text and do not infer outputs from rejected responses.
