# Post-hoc constrained compact-output comparison

After observing strict compact-output failures, the misleading four-product example and the delimiter-tolerant parsing audit, test whether enforcing output shape during decoding recovers usable decisions. This is an exploratory, post-hoc intervention; the original experiments and their failed outputs remain unchanged.

Use the same 250 original ESCI pools and 160 sampled WANDS pools for each of Qwen3-4B-Instruct-2507 and SmolLM2-1.7B-Instruct. Reuse each model's saved two-stage compact-fallback final specification (or the same fallback if invalid), candidate inputs, chunk boundaries and ordering. Remove the misleading example sentence, as in `PROTOCOL_compact_prompt_ablation.md`, for every run. Save first and at-most-once retry responses. The tasks retain their respective system instructions and binary mappings. The matched baseline uses the same engine as the corrected guided run, as described in the amendment below.

Then generate the same prompts using vLLM 0.10.2 `GuidedDecodingParams(regex=...)`, constraining each chunk to exactly its actual number of uppercase Y/N characters. The corrected comparison uses the V1 engine (`VLLM_USE_V1=1`) for both matched unconstrained and guided outputs: retain the initially recorded Qwen V1 example-removed run and add a SmolLM2 V1 example-removed run. Use temperature zero, bfloat16, maximum 32 generated tokens, context 4,096, one RTX 5090, maximum 16 concurrent sequences, eager execution and prefix caching. Let vLLM select the guidance backend; preserve logs. Before evaluating either model, a negative control asks for an incompatible word without and then with a four-label regex; stop if the unconstrained answer passes the four-label parser or the constrained answer fails it. Save both control outputs. Apply the same strict parser, and for an invalid result retry once using the original format-retry instruction and the same constraint. Record all raw first and retry outputs. An engine error or an incomplete output remains a failure, never an imputed label. This enforcement does not establish that generated labels are correct or positionally faithful.

Protocol amendment after observing the Qwen V0 trial: an initial Qwen example-removed run used V1 by default, whereas the earlier experiments and SmolLM2 ablation used V0. We initially repeated the Qwen unconstrained condition using V0 and attempted guidance in that same engine. The supposed Qwen V0 guided run reproduced every one of the 1,302 unconstrained chunks byte-for-byte, including ten invalid final chunks; local vLLM source inspection found guided-decoding processing in the V1 request path. The V0 trial therefore does **not** demonstrate active guidance and is retained as an invalid implementation attempt, not a guided result. A SmolLM2 V0 attempt had already started and is retained under the same caveat. The corrected V1 comparison and negative control were chosen after this finding; it is post-hoc and must not be compared with V0 quality or timing as if only guidance had changed. The V0 script snapshot and all attempts remain available.

Report pool and chunk completion, F1, balanced accuracy and query-macro ratio MAE for each mode on its own completed pools and, when nonempty, on identical pools completed by both example-removed modes. Also evaluate pointwise predictions and constant Y/N predictions on those same pools. If all guided pools complete, additionally report the guided plan on all attempts. Report query-cluster bootstrap intervals for paired guided-minus-unconstrained F1 and MAE only when the common subset is nonempty. Compare total completion denominators even when the common subset is empty. Do not compare offline wall-clock times across separately scheduled runs or claim this isolates model architecture, validates the reference labels, or establishes generality beyond these datasets, prompts, two models and sampling choices. Any difference from the frozen plan must be documented before claiming results.

Implementation reference: vLLM 0.10.2 structured-output example, https://docs.vllm.ai/en/v0.10.2/examples/offline_inference/structured_outputs.html.
