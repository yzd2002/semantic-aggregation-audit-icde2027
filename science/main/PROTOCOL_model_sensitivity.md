# Follow-up model-sensitivity protocol (written before this model is run)

After observing the Qwen results, repeat the same original-data experiment on the exact same 250 saved query pools with a second model, HuggingFaceTB/SmolLM2-1.7B-Instruct, revision `31b70e2e869a7173562077fd711b654946d38674`. This is a follow-up sensitivity analysis; the sample and the decision to add a model were informed by prior results, so it is not a fresh independent test set or a controlled test of architecture alone. It changes model family and parameter count together.

Use `run_full_pools.py` unchanged with the SmolLM2 model path and a new output directory. The script reconstructs the same 250 pools from the same data and seed; the saved inputs must match the Qwen run. Prompts, chunk size eight, maximum output token counts, retry rules, E/S-positive mapping, model-serving hardware, bfloat16 precision and zero-temperature decoding remain unchanged. Tokenizers and chat templates differ by model; therefore a token limit is not an identical byte limit and generated-token counts across models are not directly equivalent. The pointwise, direct JSON, two-stage JSON, and two-stage compact-fallback plans are evaluated. If any plan cannot run, report the error without inventing results.

Compare model-specific pool completion over 250 and model-specific F1, balanced accuracy, and pool-ratio MAE on that model's own common-completion subset. Also compare model-independent all-Y and lexical baselines on the same subset. Because the common subsets can differ between models, do not interpret differences in their conditional quality metrics as a paired causal model comparison. Preserve raw outputs, selected inputs, source revision and model weight hashes.

Before observing SmolLM2 outputs, also pre-specify an intersection analysis: if at least one pool completes under every plan for both models, compute each model-plan's metrics on that identical subset and use query-cluster bootstrap intervals for descriptive comparisons. Always report the size of this subset; it is selected by completion and is not a population-level estimate or a causal comparison.
