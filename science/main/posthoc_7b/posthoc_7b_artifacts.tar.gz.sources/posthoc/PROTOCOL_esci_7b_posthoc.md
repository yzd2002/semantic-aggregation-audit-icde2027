# Post-hoc Qwen2.5-7B sensitivity on the observed ESCI sample

This fixed plan is written after observing the Qwen3-4B and SmolLM2 results and all labels on the 250 previously selected ESCI query pools, but before downloading or running Qwen2.5-7B-Instruct. The sample is reused and exposed; this is not a preregistered new sample, independent replication, population estimate or human purchase-satisfaction validation. The original two-model protocol and saved inputs remain unchanged.

Use Qwen/Qwen2.5-7B-Instruct revision a09a35458c702b33eeacc393d103063234e8bc28 (7.61B parameters, Apache-2.0 as its official model card states). Download via the mirror into temporary storage and verify the four safetensors SHA-256 values and small files' Git blob hashes against the official Hugging Face revision API metadata, not only mirror metadata. Pin all local file hashes. The model has a different family version, size, tokenizer, chat template and pretraining history from the existing models; a difference cannot be attributed solely to size and more parameters do not guarantee better quality. Its prompting is not separately tuned.

Use the exact saved 250 query pools and original E/S versus C/I mapping from PROTOCOL_esci_selective_holdout.md. Preserve every candidate, chunk, local ID and ordering. Generate specification, keyed original and stable-ID reversal, actual pointwise fallback only for disagreements, identical keyed replay, and full pointwise diagnostic in that order. Use the existing runner with only a new model-name gate and a provenance field; use V1 vLLM 0.10.2, bfloat16, 4096-token context, eager execution, max 16 sequences, prefix caching, batches of 64, original caps and retry rules. Before each batch check ownership of the idle GPU; do not stop other processes. The original model run used 70% GPU-memory utilization; if initialization fails, retain the failure and record any parameter change before a separate run rather than overwriting it.

Before the first candidate model request, freeze this protocol, all existing package Python modules that can affect this run or analysis, the modified runner, selected input and metadata, versions and model asset hashes. The existing keyed and one-label incompatible-instruction negative controls must pass or no candidate evaluation is permitted. Retain the failed control or run if one occurs.

The designated descriptive comparison is the 7B run's actual selective-minus-keyed query-macro ratio MAE over pools completed by original, reverse, actual selective, replay and full pointwise; use the existing paired query bootstrap with 4,000 resamples and seed 20271202. Report completion over all pools, pooled candidate F1, balanced accuracy, ratio MAE, all-Y/all-N/lexical and full-pointwise comparators, keyed reversal/replay differences, actual fallback calls and logical input/output tokens. Include 4B and SmolLM2 existing values only as post-hoc context on the same exposed sample. Report negative, null, invalid or incomplete results as they occur; do not claim causal model-size effects or general superiority. Queries and products may be dependent and public model pretraining exposure is unknown.

Reconstruct outputs, mappings, routing, prompts, quality and bootstrap with the independent verifier and with the downloaded tokenizer if available. Preserve raw responses, source and frozen manifests; report offline inference time separately from any production latency. The model weights are not included in the artifact and temporary /dev/shm storage is not durable. The experiment has no connection to actual purchases.
