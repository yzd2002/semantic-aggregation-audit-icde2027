# Post-hoc 7B sensitivity on the previously observed WANDS and TREC-COVID samples

This plan is written after prior Qwen3-4B and SmolLM2 results, samples and labels were inspected, and before any candidate outputs from Qwen2.5-7B-Instruct. It supplements PROTOCOL_esci_7b_posthoc.md; all three are exposed samples, not new independent validation sets, general model rankings, model-size interventions, real shopper satisfaction, or clinical evaluations. The 7B model identity, revision, source and hash checks are the same as that protocol.

On the previously saved 52 WANDS selective-execution queries (1,664 judgments; Exact only is positive), run specification, original keyed, stable-ID reversal, actual selective pointwise fallback, identical replay and full pointwise diagnostic. Reuse the earlier prompt construction, per-request generation caps, temperature zero, validation, retry, 4096 context, BF16 and V1 implementation. Adapt the recorded SmolLM2 runner only for the new model and protocol, and use max 64-prompt batches with a GPU-ownership check before each batch; earlier WANDS runs submitted larger groups, so scheduler and numerical behavior differ. This limits comparisons and forbids causal attribution to model size. Abort our own run if an unrelated GPU process appears; never stop it. Preserve negative-control, failures, prompts' hashes, responses, run settings and retry/token counts.

On the previously saved 50 TREC-COVID topics (1,600 labeled title/abstract judgments; fully relevant only is positive), use the same keyed, reversal, actual selective, replay and full pointwise plans and the existing biomedical prompt, format constraints, caps and engine configuration. Adapt the recorded SmolLM2 runner only for the new model, this protocol and the same guarded 64-prompt batches. Its title/abstract inputs are truncated and cannot support patient-care claims. No new topic or document is selected.

Freeze both adapted runners, their analysis and verification scripts, the existing imported Python modules and all input samples before the 7B candidate outputs. Verify the format negative controls; never silently replace failures. For each dataset, compute completions over all attempts and quality on the common-complete pools. Report candidate F1, balanced accuracy, query-macro ratio MAE, all-Y/all-N/lexical and pointwise comparators, actual selective-minus-original paired query-bootstrap 95% interval with the existing fixed seeds and 4,000 resamples, reversal changes and logical calls/tokens. These are uncorrected, descriptive, potentially dependent across products or documents and conditioned on completion; no interval guarantees population coverage. Report negative, null, invalid or incomplete outcomes. Model architecture/version, size, tokenizer, prompt/template and scheduling change together.

Use the existing independent WANDS verifier with only the fixed expected protocol/model name adjusted; use the existing TREC independent verifier, with the downloaded tokenizer when available. Independently audit prompts, IDs, routes, parser and token counts. Save all outcomes and logs, and include reproducible hashes. Temporary model files are not durable, and no experiment modifies prior outputs or the host environment.
