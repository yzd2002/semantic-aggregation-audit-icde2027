# Planned three-dataset model-sensitivity visual

Before observing any 7B candidate output, prepare a single three-panel figure for the existing 250-query ESCI, 52-query WANDS and 50-topic TREC-COVID samples. Each panel shows the actual selective-minus-original query-macro ratio MAE and its paired 95% query-bootstrap interval for Qwen3-4B, Qwen2.5-7B and SmolLM2; negative values indicate lower selective error. Plot all nine values, regardless of sign or interval crossing zero, using the fixed saved analyzer outputs and each model's own common-complete-pool count. Show each count explicitly. If a result is unavailable, label it missing rather than substituting data. All panels use the same x scale; include zero and every interval without cropping.

These datasets and earlier model outcomes were previously observed, so the entire comparison is post-hoc. Different model-specific complete subsets, architectures, prompt templates, sizes, tokenizers and scheduling limit cross-model interpretation. The query bootstrap is uncorrected for multiple comparisons and does not remove shared-product/document dependence. Use markers with shapes as well as colors, readable labels and a restrained layout; save the exact numeric data alongside the vector and raster files. The figure is a descriptive evidence summary, not a new accuracy claim, proof of size effects, real-user satisfaction result or clinical result.
