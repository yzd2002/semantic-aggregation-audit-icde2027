# Independent WANDS dataset follow-up (fixed before model inference)

After observing the earlier ESCI results, test the same execution contracts on the independent Wayfair Annotation Dataset (WANDS), revision `3b74dcf4ba29ab8ff3e6a50b5b09fc627cb882b5`. WANDS contains 480 queries, 42,994 products and 233,448 human relevance judgments. Its annotation guidelines define `Exact` as fully satisfying a query, `Partial` as matching the entity but not all query modifiers, and `Irrelevant` as unrelated. The WANDS decision to add this evaluation was made after the ESCI results: it is an independent source/domain, not a previously unseen analysis plan or a fresh human study of purchasing behavior. The public dataset may be in model pretraining data.

**Binary target and input.** Use `Exact` -> Y and `Partial` or `Irrelevant` -> N as the primary exact-satisfaction proxy. These labels are not interchangeable with ESCI's E/S -> Y mapping. Use a task-specific system instruction asking for an exact product match to stated requirements and forbidding assumptions about unobserved properties. Annotators could see product images and pages, whereas the model sees only a truncated text view, so apparent errors can be information-availability differences. No user satisfaction or purchase outcome is observed.

**Deduplication and sampling.** Read the three pinned TSV files and verify their SHA-256 hashes. All query and product keys must be unique; all label foreign keys must match. For each `(query_id, product_id)` group, collapse repeated identical labels to a single candidate using its minimum annotation ID; remove groups with conflicting labels, and report their count. Exclude any WANDS query whose case-folded, trimmed text occurs in the ESCI pilot, validation, or original-pool samples. Select 160 eligible remaining query IDs uniformly without replacement with Python `random.Random(20271110)` from IDs with at least 32 non-conflicting judged candidates. For each chosen query, sort candidates by numeric annotation ID and product ID; sample 32 uniformly without replacement using a query-specific SHA-256-derived seed, and shuffle their order with the same RNG. These are *sampled judged pools* of 32, not full Wayfair result pages or the entire WANDS judgment lists. Do not stratify or select by observed grades. Archive selected query, product and annotation IDs, text, source labels, and order.

Serialize each candidate as `Name: ` plus the first 140 characters of the product name, `Class: ` plus 60 characters of the product class, `Features: ` plus 210 characters of its product feature text, and `Description: ` plus 140 characters of the description, separated by newlines and truncated to 600 characters total. The order and limits are fixed; they can omit material information. Ratings, query class and product images are not sent to the model.

**Plans.** Run exactly the existing original-pool execution harness and strict parsers, with the WANDS-specific input sample and system instruction substituted. Use Qwen3-4B-Instruct-2507, bfloat16, vLLM 0.10.2, one RTX 5090, 4,096-token context, at most 16 scheduled sequences, temperature zero, eager mode and a maximum of one retry. Evaluate pointwise Y/N, direct indexed JSON, two-stage indexed JSON, and two-stage compact with specification-failure fallback. Break batch input into consecutive chunks of eight; a query pool is complete only when every chunk validates. Compare the same candidate pools across plans; do not tune prompts, sampling, or format from the WANDS results.

**Metrics.** Report completion out of 160, pooled candidate F1 and balanced accuracy, and query-macro ratio MAE. Compare quality on the intersection of pools completed by all four model plans and separately report completion on the entire attempt set. On that intersection, include deterministic all-Y and all-N predictors and the same all-query-words lexical baseline used for ESCI. Use 4,000 query-ID cluster bootstrap resamples, seed `20271111`, for descriptive 95% intervals and paired F1/ratio-MAE differences from pointwise. The WANDS evaluation changes both dataset and task instruction; it cannot isolate a causal dataset effect. Completion-conditioned selection, small random pools and the benchmark's own relevance-pooling procedure constrain generalization. Retain raw responses, deterministic selection code, source hashes, outputs and analysis.

**Partial-output diagnostic.** Before examining WANDS outputs, also compute sharp completion intervals for failed pools using only valid final chunks: if `m` of `n` labels were structurally accepted and `p` of them are Y, the model-vector completions have ratios in `[p/n, (p+n-m)/n]`. For each plan's failed pools, report interval width, the fraction of accepted labels that disagree with the inherited relevance proxy, and the fraction for which that proxy's complete ratio lies inside the interval. Inclusion is descriptive: the interval covers the proxy only under additional semantic assumptions and is not a confidence interval. Apply the same diagnostic post hoc to the already observed ESCI outputs, recording its post hoc status. Do not silently fill unknown labels or use these intervals as evidence that accepted labels are correct.

**Second-model transfer.** Before examining either model's WANDS outputs, repeat the four WANDS plans on exactly the same 160 saved pools using SmolLM2-1.7B-Instruct at the revision and hash recorded in `MODEL_SENSITIVITY_SHA256.txt`. The same task instruction, chunk size, token limits, retries and GPU configuration apply; model tokenizer and chat template differ. Report completion for all attempted pools and, when available, model-specific quality on that model's four-plan common subset. If all eight plans across both models have a nonempty common intersection, report its size and descriptive paired quality; otherwise explicitly report that this intersection is empty. The choice to add SmolLM2 was informed by its earlier ESCI failure, so this is a follow-up sensitivity check, not a controlled test of architecture or a genuinely independent choice of model. Retain both models' raw outputs even if one has no complete common pools.
