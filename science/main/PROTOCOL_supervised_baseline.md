# Post-hoc supervised lexical baseline (frozen before its training and evaluation)

This follow-up is motivated by the already observed Qwen and SmolLM2 results. It is not part of the original pre-specified model-plan comparison. To add a trained, transparent non-LLM comparator, train a binary logistic regression on original ESCI labels and lexical query--product features. Do not tune its threshold, features, or hyperparameters against the 250 evaluation queries. Report unfavorable results as well as favorable ones.

Use the original Amazon Science example and product Parquet files, verified by `OFFICIAL_DATA_SHA256.txt`. Retain US, small-version, train-split examples with labels E/S/C/I and nonempty queries. Before sampling, exclude training examples whose case-folded and whitespace-trimmed query string matches any saved query from the 160-pool pilot, 500-pool validation, or 250-pool original-data evaluation. Sort examples by their example IDs, then sample 50,000 examples uniformly without replacement using pandas `random_state=20271106`. The training sampling unit is an example, not a query; some queries contribute multiple examples. E/S map to 1 and C/I to 0. Join product fields exactly as in the original-pool evaluation, in the same order, and truncate to 600 characters. Stop on duplicate product keys or missing joins; save the sampled IDs and labels to allow independent reconstruction. Distinct products can appear in both training and test queries, and pretraining exposure for the LLMs is unknown.

Create case-folded Unicode word-token sets for the query and product text. Hash query-token, product-token, shared-token and missing-query-token indicators, plus query coverage, product-token coverage, Jaccard, log-transformed query/product token-count and constant features, into 262,144 dimensions using scikit-learn `FeatureHasher(input_type='dict', alternate_sign=False)`. Fit scikit-learn logistic regression with an intercept, L2 penalty, `C=1`, `solver='lbfgs'`, `max_iter=200`, and no class reweighting. Predict Y iff estimated positive probability is at least 0.5. These choices are fixed before observing baseline output. Feature hashing can collide, and training examples are not independent at the query level.

Evaluate the fitted classifier on the same 250 original held-out pools, and separately on Qwen's 207 all-plans-complete pools. Report completion, candidate micro-F1, balanced accuracy, macro query-ratio MAE and their 95% query-ID-cluster bootstrap intervals (4,000 resamples, seed `20271108`); report paired intervals for the baseline minus Qwen pointwise F1 and ratio MAE on each identical pool subset. The classifier uses supervised labels while the LLM prompts do not, and its features see the same truncated text. Do not portray this as an apples-to-apples model cost comparison or a test of human purchase satisfaction. Save training manifest, raw per-candidate predictions, metrics, versions, and code. The 250 test pools and model-plan execution were fixed before this follow-up, but the addition of the classifier was post hoc and the sample is not an independent dataset.

## Convergence follow-up

The first training reached its pre-specified 200-iteration limit with a convergence warning. After observing that warning and its initial evaluation output, preserve the original run and repeat training from scratch with the same sample, features, solver and hyperparameters, changing only the upper limit to 1,000 iterations to address the training diagnostic. Report whether the retry converged and retain both runs and their results; this post-hoc change is not an independent replication. Do not select a run based on test-set performance.
