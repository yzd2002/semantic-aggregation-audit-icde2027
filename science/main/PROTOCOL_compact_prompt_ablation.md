# Post-hoc compact-output example ablation

Motivation: after inspecting the original SmolLM2 ESCI outputs, many compact-format responses contain `YNNY.`. The existing compact prompt asks for an exact number of Y/N characters without punctuation, but ends with `Example for 4 products: YNNY.` even when the actual chunk has eight or another number of candidates. This prompt is part of the earlier frozen experiments and their results must not be changed or discarded.

Before running this ablation, fix one change: remove that entire example sentence from the compact judgment prompt; leave every other system instruction, query, product, generated specification, chunk boundary and order, validation rule, retry instruction, decoding temperature, token limit, hardware and inference configuration unchanged. This removes both the punctuation and the mismatched-length example simultaneously; it does not isolate their individual effects. It is a post-hoc prompt change motivated by observed ESCI responses, not a fresh independent discovery or a causal comparison of model architectures.

For both the 250 original ESCI pools and the 160 sampled WANDS pools, use the saved SmolLM2 specification outputs from the prior two-stage compact-fallback plan. Parse the saved final specification with the same validator; if it is invalid, use the same direct-prompt fallback. Reuse exactly the original candidates and chunk order, issue the corrected compact prompt for each chunk, and retry once if its output fails the original strict parser. Generate with SmolLM2-1.7B-Instruct, temperature zero, bfloat16, vLLM 0.10.2, max context 4,096, maximum 32 generated tokens, one RTX 5090, maximum 16 concurrent sequences and eager execution. Retain every first and retry response.

Report completion out of all attempted pools, valid chunks before and after retry, and candidate F1, balanced accuracy, and query-macro ratio MAE on each corrected plan's own completed pools. Compare corrected and original results on the exact common-complete pools if that intersection is nonempty; otherwise state that paired quality is unavailable. Include all-negative and all-positive baselines on the same corrected-complete subset. Count output strings that literally copy the removed example. Different completion subsets can be selected, and changes in the prompt can change semantic labels as well as formatting. Do not claim a universal model failure or improvement from this single prompt ablation, and do not compare the wall time directly to other runs.
