# Post-hoc calibrated embedding reference on WANDS

This protocol is written after observing all earlier WANDS LLM, lexical and supervised-lexical outcomes and before embedding the recorded candidate pools or inspecting the new embedding scores. It adds a semantic similarity reference, not a new blind test, new data source, or a claim that a simple calibrated bi-encoder is a state-of-the-art product ranker. It uses relevance labels for training the threshold, unlike the evaluated zero-shot LLM plans. The same labeled WANDS candidate pools, Exact=positive mapping and truncated text are reused; annotators could consult product pages and images unavailable here.

## Fixed data and representation

Use the 160 original WANDS query pools and 5,120 candidates as training; use the previously recorded 160-, 96- and 52-query samples as evaluation. Before inference confirm that training and each test sample have no case-folded, trimmed query-string overlap and no overlap in sampled product IDs or exact serialized product text. The prior Qwen, lexical and supervised outputs remain fixed. Training-set labels are used only for fitting the scalar threshold described below, not for fine-tuning the model. Test labels are used only after this threshold is fixed. Within-sample repeated product IDs and possible pretraining exposure remain limitations.

Use the locally cached Qwen/Qwen3-Embedding-0.6B model matching `MODEL_EMBEDDING_SHA256.txt` (weights and tokenizer checked against the pinned public revision). With transformers 4.57.1, use `AutoTokenizer` with left padding and the model's unchanged tokenization; `AutoModel` in eval mode with bfloat16, SDPA, cache disabled, on one RTX 5090. Pool the last non-padding token and L2-normalize to float32 as in the official model card. Prefix each query with `Instruct: Given a web search query, retrieve relevant passages that answer the query\nQuery:`; supply the saved candidate text as the document without an instruction. Process queries and first-occurrence unique document strings in the recorded order in batches of 32. Refuse inputs exceeding 1,024 model tokens rather than silently truncate them. This limit is separate from the already recorded source-text truncation. Save the normalized float32 query and document vectors and exact index mapping, all candidate scores, model/tokenizer fingerprints, token counts, runtime versions and actual GPU memory peak. Embedding inference time is an offline batch including tokenization, not online latency or an end-to-end speed comparison; model load and subsequent analysis are excluded. A separate unrelated synthetic test confirms that the model loads and ranks a simple relevant passage first.

For each candidate use the float32 dot product of its saved unit-normalized query and document embeddings. Fit one shared scalar threshold on the 5,120 training candidates: evaluate every unique training score, predict Y for score >= threshold, select the threshold that maximizes pooled training F1, and break ties by selecting the largest threshold. No calibration from test labels, model fine-tuning, feature selection or test-set tuning is allowed. Save training threshold and training confusion counts.

## Fixed comparison and limitations

On each of the three existing samples, compare the calibrated embedding predictions with the previously defined Qwen plan, all-query-words rule and supervised lexical reference from `run_wands_supervised_reference/`. Qwen uses keyed JSON on the 160-query exposed holdout, trace-derived pointwise fallback on 96 queries and actual selective fallback on 52; rows across samples are not direct plan comparisons. On common complete pools report pooled F1 and balanced accuracy and query-macro ratio MAE. For the embedding minus Qwen contrasts, report query-cluster bootstrap percentile 95% intervals with 4,000 draws and seeds 20271221, 20271222 and 20271223 for the 160, 96 and 52 query samples. These comparisons are post-hoc, unadjusted for multiplicity, and conditional on selected judged products; the intervals do not address repeated products or selection bias. Preserve all results, including poor or null outcomes.

Freeze the protocol, code, model fingerprints, sample inputs and prior reference predictions before embedding inference. Independently reconstruct index mappings, scores, the training threshold, labels, summary metrics and bootstrap intervals from the saved vectors and inputs. That verification does not constitute a fresh-machine model rerun; rerunning model inference can vary across hardware, software and batch conditions.
