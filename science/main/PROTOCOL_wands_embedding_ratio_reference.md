# Post-hoc ratio-oriented threshold for a WANDS embedding reference

This analysis is designed after observing the WANDS test samples, earlier embedding, lexical and Qwen results, and other ratio-oriented references. It uses saved vectors and responses; it performs no new model inference and is not a blind test or independent data source. The pretrained embedding model is fixed and receives no task fine-tuning. The scalar decision threshold uses 5,120 labeled training candidates; zero-shot Qwen and the all-query-words rule do not receive those labels.

Reconstruct float32 query–document dot products from the existing saved unit-normalized vectors and index mapping, using the same scoring operation as the original embedding experiment. Verify query ordering, test scores and the previously saved F1-threshold predictions and metrics. Check that normalized query strings, sampled product IDs and exact serialized product texts are disjoint between training and each test sample. Use the same Exact-positive label mapping and 32 candidates per query.

Choose one common threshold using only the 160 training-query labels: evaluate every distinct training score and a threshold immediately above the maximum (all-negative), select the threshold minimizing query-macro ratio MAE, and break ties in favor of the highest threshold. No test label, test metric or test reweighting may be used to set the threshold. The threshold is selected on the same training data used to report its training error, so that error is not an independent estimate. Retain the original training-F1 threshold as a separate baseline; neither threshold calibrates probabilities.

On the exposed 160-query keyed, 96-query trace-fallback and 52-query actual selective samples, report binary candidate F1, balanced accuracy and query-macro ratio MAE of both embedding thresholds, Qwen and the all-query-words rule. Compute 4,000 paired query-cluster bootstrap draws for ratio-threshold minus Qwen and minus all-query-words, using the prior embedding-study seeds 20271221, 20271222 and 20271223. Verify the prior F1-threshold-versus-Qwen intervals against saved results. Also compute post-hoc query–product reweighting ranges using the same seeds 20261031, 20271128 and 20271201 and ordering as the prior ratio-reference sensitivity. Product weights change the candidate pools and the estimand: these are sensitivity ranges, not confidence intervals for the original fixed-pool ratio MAE. Verify the previously reported lexical-minus-Qwen product ranges exactly.

All comparisons are descriptive, unadjusted for multiple comparisons, reuse previously exposed data and depend on the chosen relevance proxy and truncated text. Neither cluster procedure corrects selection bias, repeated products, pretraining exposure or missing customer-satisfaction labels. Report adverse and null outcomes; preserve protocol, source hashes, threshold, all results, code and independent checks.
