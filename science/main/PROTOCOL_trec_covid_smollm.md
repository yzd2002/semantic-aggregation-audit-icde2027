# Secondary SmolLM2 sensitivity on the exposed TREC-COVID sample

This follow-up was designed after observing Qwen's TREC-COVID results but before generating any SmolLM2 output on these documents. It reuses exactly the 50 topics and 1,600 selected judged documents in `trec_covid_transfer_selection/`; it is not a new sample or a blinded replication. Its purpose is to report whether the same cross-domain keyed and actual selective procedure completes and how its quality behaves for a second, smaller model. Model family, size, tokenizer and chat template differ; no comparison can isolate their individual effects, and this does not establish clinical utility or shopper satisfaction.

Check the frozen Qwen sample and original source/analysis hashes. Verify the locally loaded SmolLM2-1.7B-Instruct weights and recorded tokenizer/configuration hashes against `MODEL_SENSITIVITY_SHA256.txt`. Use the same vLLM 0.10.2 V1, process-local declared-dependency overlay, GPU settings, textual system and task prompts, original/reversed stable-ID keyed output, actual selective pointwise fallback, identical-prompt replay, full pointwise comparator, strict parsers, retry caps, negative guidance controls, token accounting and GPU-ownership checks as `PROTOCOL_trec_covid_transfer.md`. The runner differs only in the recorded protocol name, the source selection protocol check and the required model name. Chat serialization is model-specific. Record and enforce each model's actual context limits before inference. Preserve raw outputs, all failures, exact prompts via reproducible inputs and hashes, timing scope and token counts; never use later full-pointwise judgments to construct the actual selective result.

Compute the same completion, pooled F1, balanced accuracy, ratio MAE, replay and reversal changes and lexical/constant comparators, using the unchanged saved analysis implementation. Describe the within-SmolLM2 selective-minus-original ratio MAE with 4,000 query-bootstrap draws (seed `20271032`) and the query–document resampling sensitivity (seed `20271033`) from the original protocol and its amendment. No success threshold or inference on superiority is pre-specified. Query–document resampling reweights the observed candidate pools and is not an exact fixed-pool interval. All intervals are conditional on this exposed, judged and truncated sample; the later selection of this model and follow-up, public pretraining exposure, potential execution variation and multiple comparisons limit interpretation.

Report SmolLM2 metrics alongside the saved Qwen metrics descriptively, preserving null or adverse results. Do not attribute differences to model size or architecture alone and do not infer unjudged-document coverage, production latency or medical correctness. A successfully parsed output does not establish a correct judgment. Record engine cleanup warnings and retain all unsuccessful attempts rather than replacing them.
