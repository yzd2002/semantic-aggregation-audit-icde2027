# Post-hoc within-chunk order sensitivity

This analysis was designed after the ESCI, WANDS, prompt-ablation and guided-decoding results were examined. It tests a concrete limitation of positional compact labels; it is neither a new independent dataset nor a pre-registered population-level experiment.

For each of Qwen3-4B-Instruct-2507 and SmolLM2-1.7B-Instruct, use the already archived 250 ESCI pools and 160 WANDS pools and that model's saved final query specification or the same direct fallback. The reference condition is the corresponding `run_guided_compact_*_v1` output: the example-removed compact prompt, exact-length uppercase Y/N regex, vLLM 0.10.2 V1, zero temperature, bfloat16, 4,096-token context, a maximum of 32 generated tokens, RTX 5090, at most 16 concurrent sequences, eager execution and prefix caching.

The new condition reverses the candidates **inside each existing chunk**, leaving the pool, query, specification, chunk boundaries and chunk membership unchanged. The displayed local candidate identifiers are reassigned consecutively to match their new positions, as in the original prompt. Generate with the same system and user templates and the same guided-decoding configuration. Before data inference, run the same incompatible-word negative control and fail closed if the constraint does not take effect. Apply the original strict parser and one retry for an invalid chunk. Reverse the resulting label vector back into original candidate order before computing any metric; never impute missing labels.

Record every first and retry output, position mapping, completeness and inference configuration. For each model and dataset, compare conditions on the identical pools completed in both, and report the common denominator; separately report completion over all attempted pools. Report the share of candidate decisions that change, the count of pools with at least one changed decision, the distribution of absolute changes in the estimated pool ratio, candidate F1 and balanced accuracy, and query-macro ratio MAE against the inherited task-specific labels. Construct 4,000 paired query-cluster bootstrap intervals for candidate F1 difference, ratio-MAE difference, and the candidate-weighted label-change fraction, with a fixed seed. Include no universal causal claim: changing order also changes the local identifier associated with each product, prompt context and possibly nondeterministic execution; one deterministic reversal does not characterize all permutations, pools, prompts, models or semantic correctness. Do not compare separately scheduled offline runtimes as latency or general speedups.

Before viewing the reversal results, also specify an exploratory agreement-only abstention diagnostic: accept a candidate's label only when original and reversed judgments agree, and abstain on disagreements. On the same common-complete pools, report accepted candidates and their empirical disagreement with the dataset reference, the fraction abstained, and the number and mean width of the `k=0` completion intervals containing the reference pool ratio. The interval is conditional on all accepted labels being correct; it is not a confidence or coverage guarantee, and inclusion can occur through cancellation of accepted-label errors. This diagnostic reuses the two already-generated judgments and does not represent an independently calibrated or deployed plan.

Raw responses, the exact mapping back to original order, source-run identifiers, verification scripts and analysis outputs must all be retained. If the negative control fails or any pool fails validation, report that outcome without silently replacing or dropping it.
