# Post-hoc query–product reweighting of WANDS ratio references

This check is designed after the three test samples, Qwen and lexical outputs, trained-reference scores, selected ratio threshold, and prior query-only intervals have all been observed. It introduces no new labels or model calls and is not a blind test. Its purpose is to characterize sensitivity to repeated products when comparing the saved ratio-oriented supervised reference with Qwen and an all-query-words baseline.

For the 160-query keyed holdout, 96-query trace-derived fallback sample, and 52-query actual selective sample, use the same stored pools, original label mapping, complete predictions and threshold 0.5837454647017262 selected from training-fold predictions. Compare (1) ratio-threshold minus Qwen, (2) ratio-threshold minus all-query-words, (3) all-query-words minus Qwen, and (4) mean-score ratio minus Qwen. The score mean estimates a ratio and does not provide candidate labels. Do not refit a model or choose any threshold using test labels.

For each sample independently draw with replacement the same number of query IDs and the same number of distinct product IDs as observed, using NumPy `default_rng`: seeds 20261031, 20271128 and 20271201 for the 160, 96 and 52 samples. Query draws precede product draws on each iteration. Sort numeric product IDs and keep the saved query order. Each judgment receives its product multiplicity; the reference and all predicted fractions are recomputed within each selected query using product weights. Take the query-multiplicity-weighted mean of the paired absolute-error differences. Fail if any selected query has zero total product weight. Report 2.5th and 97.5th percentiles of 4,000 draws regardless of direction.

The same 96- and 52-query seeds and ordering were used by the earlier query–product sensitivity analyses. Separately recompute the original Qwen selective-minus-keyed contrast and verify that its range reproduces those recorded outputs. A product reweight changes each candidate pool and its reference fraction, so this range is not an exact confidence interval for the original fixed-pool MAE. Results remain exploratory, unadjusted for multiple comparisons and conditional on the sampled judged products, existing model outputs, training labels and public datasets; query–product resampling cannot correct selection bias or establish population coverage. Preserve all results and input hashes.
