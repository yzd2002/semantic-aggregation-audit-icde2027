# Post-hoc two-order midpoint ratio reference

This analysis is exploratory: all datasets, models, and the original selective-execution outcomes were already observed. It does not claim independent validation, prospective registration, or a new model run.

For each complete pool with valid ID-aligned keyed original and stable-ID-reversed labels, the midpoint estimates the fixed-pool positive ratio as (number of Y labels in the original + number of Y labels in the reversal)/(2 * number of candidates). It uses the same two keyed passes as disagreement fallback and has no third pointwise request. It is a fractional ratio estimate, not a candidate-label vector; candidate F1 and balanced accuracy are not defined. Its cost is the recorded specification and two keyed passes, excluding replay, full pointwise diagnostics, loading, training, or time. The 96-query fallback is reconstructed from saved pointwise traces and its cost is virtual; the other fallback outputs are saved actual offline execution. None of these costs implies online latency or a future-system speedup.

Fixed comparands before this specific computation: seven existing Qwen3-4B and SmolLM2 settings covering WANDS 96 and 52, ESCI 250 and TREC-COVID 50; five existing Qwen2.5-7B post-hoc settings (ESCI and WANDS each unconstrained and schema-guided, TREC with official narratives). No settings are selected based on whether midpoint looks better. For each model/setting, use the common subset where both keyed vectors and selective output are complete. Also report separate completion numbers. Check every query/topic association, chunk start and local-ID map; compare original and selective MAE against published summaries when available.

Report query-macro absolute ratio error for original, reverse, midpoint and selective; the paired difference is selective minus midpoint, plus a 95% percentile query-bootstrap interval from 4,000 draws. Bootstrap seed is 20261101 + setting index in the fixed order. In a secondary sensitivity, independently draw exponential product/document weights and query-bootstrap counts, recompute weighted ratios inside each query, and report the 2.5/97.5% range of selective-minus-midpoint over 4,000 draws (seed 20262101 + setting index). This changes pool weights and hence the estimand; it is not a fixed-pool confidence interval. Intervals are unadjusted, samples share benchmark sources, some models reuse identical queries, and no population coverage is asserted.

The algebraic comparator is exact: for any two fixed complete ratio outputs a and b and any reference r in [0,1], |(a+b)/2-r| <= (|a-r|+|b-r|)/2 by convexity; the midpoint is not guaranteed better than either individual output or selective fallback. No labels or thresholds are used to choose the midpoint. Track inputs and this protocol by SHA-256 before running. Independent reconstruction and synthetic cases must be checked after calculation.
