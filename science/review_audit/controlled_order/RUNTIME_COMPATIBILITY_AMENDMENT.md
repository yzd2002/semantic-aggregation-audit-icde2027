# Pre-inference runtime compatibility amendment

Recorded after sample selection and before any new model judgment. The original runtime attempt failed while constructing a Gloo process group: Gloo tried to enumerate `/sys/bus/pci/devices`, which this execution environment forbids. Explicit loopback/eth0 settings reproduce the failure in CPU-only probes; the compiled build does not support UV transport. The original failures and probe logs are retained. No permissions, sysfs contents, global packages or existing processes are changed.

For this single-GPU, single-rank experiment only, a process-local adapter redirects `torch.distributed.new_group(ranks=[0], backend='gloo')` to a real NCCL singleton group, only inside an already initialized NCCL world with rank 0 and world size 1. All other attempted Gloo substitutions fail. The adapter guards normal tensor/object communication methods on redirected groups and raises if any is called; it fabricates neither tensors nor communication results. Real NCCL barriers, metadata queries and group destruction remain allowed.

The inspected local vLLM 0.10.2 GroupCoordinator creates CPU groups unconditionally but returns directly from its tensor/object collective paths when world size is one. Device communicators and message-queue broadcasters are only created above world size one; node counting also returns one without a collective. These exact source files are hashed in the runtime amendment. A real singleton-NCCL probe must pass and deliberately verifies rejection of a CPU all-reduce. The full incompatible-instruction grammar controls and synthetic smoke must still pass before new data inference.

Both planned models use the identical adapter, launch configuration, fixed prompts and request schedule. This is an explicit inherited-runtime compatibility deviation from an unmodified vLLM installation; it is not a fresh-machine replication. Numerical model kernels, weights, grammar, sampling, pool construction and analysis are unchanged. No speedup or per-plan latency claim is based on this run. The original frozen scripts and manifests remain unchanged; the amended launcher and adapter have their own hash manifest.

Upstream source used to identify the failed best-effort network-interface-to-PCI lookup: https://raw.githubusercontent.com/facebookincubator/gloo/main/gloo/common/linux.cc (read on 2026-11-02). The installed stack and retained traceback, rather than upstream line numbering, establish the actual local failure.

The amended v3 runner also records each block submission before generation, so a later interruption can distinguish submitted-but-unreturned jobs from never-submitted jobs. This is provenance logging only. Original supplemental field names based on returned records must not be misread as submission evidence in an interrupted run.
