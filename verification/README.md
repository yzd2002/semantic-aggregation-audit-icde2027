These files preserve completed producer-side checks on actual scientific data. They do not establish anonymous public acquisition or a clean-environment GPU rerun. No inference, experiment, CPU scientific replay or manuscript rebuild was run to create this staging tree; file hashes and copy bytes were checked.

- [Core one-command result](core/ONE_COMMAND_RESULT.json): actual compact safe extraction and CPU mathematical replay for the 36 main configurations and 16 budget-follow-up policies.
- [Archive-module fix receipt](core/REAL_ARCHIVE_MODULE_FIX.json): corrected root-level source-file classification and actual rearchive/replay status.
- [CPU replay report](core/CPU_REPLAY_REPORT.json) and [budget-analyzer agreement](core/BUDGET_ANALYZER_AGREEMENT.json).
- [Actual runtime and archive verification](final_audit/ACTUAL_RUNTIME_AND_ARCHIVE_VERIFICATION.json), [readout](final_audit/READOUT.md), complete summary CSVs and the original `finalize_actual.py` audit source.
- [Complete verified numbers](final_audit/COMPLETE_VERIFIED_NUMBERS.json.gz): lossless gzip of the unchanged JSON; compression is only a transport choice.
- The [post-hoc native-vector supplement](../repro/real_engine_20261106/posthoc/) and [stopping-audit files](../repro/real_engine_20261106/stopping_audit/) retain their own actual producer-side replay receipts.

The publisher adds the final 177 parts and Git-blob-mapped aggregate index after this local source staging step, then performs and records any anonymous public validation separately. No mock reviews, user submission material, model weights or runtime cache are included here.
