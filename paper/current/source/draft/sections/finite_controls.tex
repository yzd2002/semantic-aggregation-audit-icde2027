\section{Alternatives When Only COUNT Is Needed}
\label{sec:finite}
Some queries need only a count; others reuse individual labels. Because row errors can cancel in COUNT (Section~\ref{sec:objects}), we evaluate established sampling controls for both targets. These offline controls do not select batch sizes: one audits an existing COUNT, two audit row accuracy, and another estimates COUNT directly. Their target $y$ is a fixed vector of supplied labels or, where available, recorded singleton labels; write $C_y=\sum_i y_i$. The source-label results below use $y_i=g_i$ and hence $C_y=G$. One lookup of a target label is one oracle query. These lookups are not priced as online model calls or new human annotations.

\subsection{Auditing an Existing COUNT}
Take one simple random sample without replacement of $m=\min(1,024,N)$ target labels. Here $N$ is the whole input, $n$ was the earlier check's probe budget, and $m$ is this separate audit's sample size. The question is whether the \emph{unchanged} returned count $C_b$ is within $.05N$ rows of $C_y$. This follows classical sample-based aggregate auditing; we do not report a corrected-count estimator~\cite{sampleclean,blazeit}.

Split the completed plan into rows it labels positive ($b_i=1$) and negative ($b_i=0$). Errors in the positive group are false positives, which raise COUNT; errors in the negative group are false negatives, which lower it. Within each group, hypergeometric (HG) inversion asks which total error counts could plausibly produce the observed sample under sampling without replacement. It keeps the counts not excluded by the allotted tail tests and takes their smallest and largest values as bounds. These bound all mistakes in the group, rather than only the sampled mistakes. Denote these full-input error-count bounds by $[L_+,U_+]$ and $[L_-,U_-]$, respectively.

The signed COUNT error $C_b-C_y$ is false positives minus false negatives. Total wrong rows are their sum. On the same joint coverage event, their intervals are therefore
\begin{equation}
\begin{aligned}
I_{\rm count}&=[L_+-U_-,\ U_+-L_-],\\
I_{\rm row}&=[L_++L_-,\ U_++U_-].
\end{aligned}
\label{eq:count_bounds}
\end{equation}
Here $I_{\rm count}$ bounds the signed COUNT error, while $I_{\rm row}$ bounds the number of wrong labels. For the first lower endpoint, subtract the largest possible number of misses from the smallest possible number of false positives; reverse these choices for the upper endpoint. Addition gives the row-error interval. All endpoints count rows, not percentages.

For an arithmetic illustration, suppose $N=2,000$ and the two error bounds are $[60,80]$ and $[50,70]$. These are assumed endpoints, not new experimental results. COUNT error lies in $[-10,30]$, whereas wrong rows lie in $[110,150]$. The 5\% tolerance is 100 rows: the COUNT bound passes, but the row bound does not. The \emph{COUNT gate} implements the first decision, requiring all of $I_{\rm count}$ to lie within $[-.05N,.05N]$. It checks the unchanged returned count. The \emph{stratified row gate} requires the upper endpoint of $I_{\rm row}$ to be at most $.05N$. A separate \emph{unstratified row gate} inverts one HG interval for all sampled mismatches, without splitting the input; neither row method is uniformly tighter.

\paragraph{Fixed-sample construction.}
We first draw the overall sample, then condition on its observed group sample sizes. With total error budget $\alpha=.05$, each of $H$ nonempty groups receives $\alpha/H$, divided between its two tails. With two groups, each tail receives .0125. An empty group contributes zero; an unsampled nonempty group retains the full possible range from zero to its size. A sole nonempty group receives full $\alpha$. The count and row intervals share this joint event; no additional split between their two arithmetic transforms is needed.

Concretely, consider a group of $M$ rows with $t$ sampled rows and $x$ observed errors. For each candidate total error count $E\in\{0,\ldots,M\}$, let $X_E$ count errors in $t$ draws without replacement from that group if it contains $E$ errors. Retain $E$ when both $\Pr(X_E\le x)$ and $\Pr(X_E\ge x)$ are at least $\alpha/(2H)$. The smallest and largest retained integers are that group's endpoints. This is the discrete HG inversion used for both groups; the unstratified row gate uses the whole input as one group.

\subsection{Which Recorded Outputs Are Eligible?}
The canonical source-label audit requires a complete strict plan vector. All $36\times2=72$ fixed-plan vectors and 26 checked-policy vectors qualify, giving 98 plan/configuration pairs. It does not need a strict singleton reference because the source labels already provide $y$. The native sensitivity uses 108 delivered vectors: three plans for each of the 36 configurations, with the same sampling order and fixed look. These 98/108 denominators count plan vectors; the main experiment still has 36 configurations and its primary comparison still has 12.

Each method applied to one fixed label vector has a nominal 95\% coverage guarantee over its audit sample. Labels are fixed before the audit, so dependence during their generation does not invalidate this fixed-population sampling argument~\cite{worcs}. We use one fixed look; repeatedly checking until passing or selecting a favorable method afterward would need different coverage control~\cite{bargain}. Source annotation quality and a future model replay remain separate targets.



\subsection{Observed COUNT-Only Outcomes}
\label{sec:audit_results}
Under the main strict-vector eligibility rule, the source-label COUNT gate accepts 24/98 complete plan/configuration pairs; both the stratified and unstratified row gates accept 3/98 (Table~\ref{tab:finite_results}). The 21 additional COUNT passes concern aggregate accuracy, not reusable row labels. No accepted source COUNT falls outside additive $.05N$ tolerance in these observed vectors. The post-hoc native-vector sensitivity evaluates 108 pairs, accepting 27 COUNTs and three row-gate passes. Its three extra COUNT passes are Qwen fallback vectors; it changes neither calibration nor deployment.



\subsection{Estimating COUNT Without a Complete Plan}
Direct approximate query processing (AQP) samples target labels without first obtaining a full batch label vector. It bounds the total number of positives by the same HG inversion: $M=N$, $t=m$, $x$ is the sampled positive count, and each tail receives $\alpha/2$. The resulting interval bounds $C_y$; AQP reports its midpoint and checks width at most $.1N$. It uses $m$ target-label queries and no full batch inference. Unlike either row gate, it remains defined without a complete plan vector. An interval's width and whether it covers the target are separate outcomes.


Direct AQP has a readout for every configuration regardless of batch completion. The same source-only estimate is reused across model/cache configurations sharing a workload, size and sample. The artifact reports all 12 distinct workload/size intervals in \texttt{direct\_AQP\_unique\_inputs.csv}, along with all 36 configuration entries. Every interval has width at most $.1N$, but realized coverage is 32/36 entries, or 11/12 distinct pairs. Movie other at $N=2,048$ is uncovered: $G=1,418$, sample positives 732/1,024, HG interval $[1,423,1,504]$. Its midpoint 1,463.5 gives $e_N=2.22\%$ and $e_G=3.21\%$. That sample is reused in four configurations. Width sufficiency and the repeated miss give no matrix-wide guarantee. The offline label lookups are not priced as native calls.
