\section{Alternatives When Only COUNT Is Needed}
\label{sec:finite}
Some queries need only the final count, while others will reuse the individual labels. The cancellation in Section~\ref{sec:objects} makes these different targets. We therefore evaluate established sampling controls offline: one checks an existing COUNT, two check row accuracy, and another estimates COUNT directly. Their target $y$ is a fixed supplied source vector, or a recorded singleton vector where available; write $C_y=\sum_i y_i$. A target-label lookup counts as one oracle query. These lookups are not priced as online model calls or new human annotations.

\subsection{Auditing an Existing COUNT}
Take one simple random sample without replacement of $m=\min(1,024,N)$ target labels. Here $N$ is the whole input, $n$ was the earlier check's probe budget, and $m$ is this separate audit's sample size. The question is whether the \emph{unchanged} returned count $C_b$ is within $.05N$ rows of $C_y$. This follows classical sample-based aggregate auditing; we do not report a corrected-count estimator~\cite{sampleclean,blazeit}.

Split the completed plan into its predicted-positive and predicted-negative rows. Errors in the positive group are false positives, which raise COUNT; errors in the negative group are false negatives, which lower it. Within each group, hypergeometric (HG) inversion asks which total error counts could plausibly produce the observed sample under sampling without replacement. It keeps the counts not excluded by the allotted tail tests and takes their smallest and largest values as bounds. These bound all mistakes in the group, rather than only the sampled mistakes. Denote these full-input error-count bounds by $[L_+,U_+]$ and $[L_-,U_-]$, respectively.

The signed COUNT error $C_b-C_y$ is false positives minus false negatives. Total wrong rows are their sum. On the same joint coverage event, their intervals are therefore
\begin{equation}
\begin{aligned}
I_{\rm count}&=[L_+-U_-,\ U_+-L_-],\\
I_{\rm row}&=[L_++L_-,\ U_++U_-].
\end{aligned}
\label{eq:count_bounds}
\end{equation}
For the first lower endpoint, subtract the largest possible number of misses from the smallest possible number of false positives; reverse those choices for the upper endpoint. Addition gives the second interval. Every endpoint counts rows.

For an arithmetic illustration, suppose $N=2,000$ and the two error bounds are $[60,80]$ and $[50,70]$. These are assumed endpoints, not new experimental results. COUNT error lies in $[-10,30]$, whereas wrong rows lie in $[110,150]$. The 5\% tolerance is 100 rows: the COUNT bound passes, but the row bound does not. The \emph{raw-COUNT gate} implements the first decision, requiring all of $I_{\rm count}$ to lie within $[-.05N,.05N]$. The \emph{stratified row gate} requires the upper endpoint of $I_{\rm row}$ to be at most $.05N$. A separate \emph{unstratified row gate} inverts one HG interval for total sampled mismatches; neither row method is uniformly tighter.

\paragraph{Fixed-sample construction.}
We first draw the overall sample, then condition on its observed group sample sizes. With total error budget $\alpha=.05$, each of $H$ nonempty groups receives $\alpha/H$, divided between its two tails. With two groups, each tail receives .0125. An empty group contributes zero; an unsampled nonempty group retains the full possible range from zero to its size. A sole nonempty group receives full $\alpha$. The count and row intervals share this joint event; no additional split between their two arithmetic transforms is needed.

\subsection{Which Recorded Outputs Are Eligible?}
The canonical source-label audit requires a complete strict plan vector. All $36\times2=72$ fixed-plan vectors and 26 checked-policy vectors qualify, giving 98 plan/configuration pairs. It does not need a strict singleton reference because the source labels already provide $y$. The native sensitivity uses 108 delivered vectors: three plans for each of the 36 configurations, with the same sampling order and fixed look. These 98/108 denominators count plan vectors; the main experiment still has 36 configurations and its primary comparison still has 12.

Each method/vector pair has its own nominal 95\% sampling scope. Labels are fixed before the audit, so dependence during their generation does not invalidate this fixed-population sampling argument~\cite{worcs}. We use one fixed look; repeatedly checking until passing or selecting a favorable method afterward would need different coverage control~\cite{bargain}. Source annotation quality and a future model replay remain separate targets.



\subsection{Observed COUNT-Only Outcomes}
\label{sec:audit_results}
Under the main strict-vector eligibility rule, the source-label raw-COUNT gate accepts 24/98 complete plan/configuration pairs; both the stratified and direct HG row gates accept 3/98 (Table~\ref{tab:finite_results}). The 21 additional COUNT passes concern aggregate accuracy, not reusable row labels. No accepted source COUNT falls outside additive $.05N$ tolerance in these observed vectors. Its three extra COUNT passes are Qwen fallback vectors; it changes neither calibration nor deployment.

\subsection{Estimating COUNT Without a Complete Plan}
Direct approximate query processing (AQP) samples target labels without first obtaining a full batch label vector. It inverts the sample's positive count to obtain an HG interval for $C_y$, reports its midpoint, and checks width at most $.1N$. It uses $m$ target-label queries and no full batch inference. It remains defined even if a batch operator fails to return a complete vector. An interval's width and whether it covers the target are separate outcomes.


Direct AQP has a readout for every configuration regardless of batch completion. The same source-only estimate is reused across model/cache configurations sharing a workload, size and sample. The artifact reports all 12 distinct workload/size intervals in \texttt{direct\_AQP\_unique\_inputs.csv}, along with all 36 configuration entries. Every interval has width at most $.1N$, but realized coverage is 32/36 entries, or 11/12 distinct pairs. Movie other at $N=2,048$ is uncovered: $G=1,418$, sample positives 732/1,024, HG interval $[1,423,1,504]$. Its midpoint 1,463.5 gives $e_N=2.22\%$ and $e_G=3.21\%$. That sample is reused in four configurations. Width sufficiency and the repeated miss give no matrix-wide guarantee. The offline label lookups are not priced as native calls.
